class FenwickTree:
    def __init__(self, size):
        self.n = size
        self.tree = [0] * (self.n + 1)
    
    def update(self, index, delta=1):
        while index <= self.n:
            self.tree[index] += delta
            index += index & -index
    
    def query(self, index):
        res = 0
        while index > 0:
            res += self.tree[index]
            index -= index & -index
        return res

### **Explanation**
- **Coordinate Compression**: This step ensures that even if the permutation contains large numbers, we can work within a manageable range, which is crucial for the efficiency of the Fenwick Tree.
- **Fenwick Tree Operations**: The `update` method adds an element to the tree, and the `query` method retrieves the count of elements less than the current element. This allows us to efficiently count inversions as we process the array.
- **Traversal Direction**: By processing the array from right to left, we ensure that when we query the Fenwick Tree, all elements to the right (which could form inversions with the current element) have already been considered.

This approach ensures an **O(N log N)** time complexity, making it suitable for large permutations.

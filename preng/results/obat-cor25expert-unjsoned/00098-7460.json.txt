To compute the nth term of the sequence defined by the values:

```
1, 3, 10, 35, 126, 462, ...
```

we observe that these numbers correspond to the **central binomial coefficients divided by 2**, i.e.,

$$
a(n) = \frac{1}{2} \binom{2(n+1)}{n+1}
$$

This can be derived from the recurrence relation:

$$
a(n) = \frac{2(2n + 1)}{n + 1} \cdot a(n - 1)
$$

with the base case:

$$
a(0) = 1
$$

This recurrence allows us to compute each term based on the previous one, using only integer arithmetic (since the division is always exact).

---

### ✅ Python Implementation

Here is a recursive Python function that computes the nth term of the sequence using the derived recurrence:

```python
def sequence(n):
    if n == 0:
        return 1
    return (2 * (2 * n + 1) * sequence(n - 1)) // (n + 1)
```

### 📝 Notes

- The function assumes **0-based indexing**, i.e., `sequence(0)` returns the first term `1`.
- The recurrence is efficient and avoids floating-point arithmetic by using integer division (`//`).
- For large values of `n`, consider memoization or iterative approaches to improve performance.

To compute the **primorial of a number `n`**, we define it as the product of all **prime numbers less than or equal to `n`**. This is a well-known mathematical concept and is often denoted as `n#`.

---

### ✅ Problem Summary

Given a non-negative integer `n`, return the product of all prime numbers `p` such that `p ≤ n`.

- If `n < 2`, there are no primes ≤ `n`, so the result is `1`.
- For `n ≥ 2`, we generate all primes up to `n` and compute their product.

---

### 🧠 Approach

1. **Edge Case Handling**:
   - If `n < 2`, return `1` since there are no primes in this range.

2. **Prime Generation**:
   - Use the **Sieve of Eratosthenes** to efficiently generate all primes up to `n`.

3. **Product Calculation**:
   - Multiply all the primes found in the sieve.

---

### 🧪 Example

For `n = 7`:
- Primes ≤ 7 are `[2, 3, 5, 7]`
- Product = `2 * 3 * 5 * 7 = 210`

---

### 🧾 Python Implementation

```python
def primorial(n):
    if n < 2:
        return 1

    # Sieve of Eratosthenes to find all primes up to n
    sieve = [True] * (n + 1)
    sieve[0] = sieve[1] = False
    for i in range(2, int(n ** 0.5) + 1):
        if sieve[i]:
            sieve[i*i : n+1 : i] = [False] * len(sieve[i*i : n+1 : i])

    # Extract primes and compute product
    primes = [i for i, is_prime in enumerate(sieve) if is_prime]
    product = 1
    for p in primes:
        product *= p

    return product
```

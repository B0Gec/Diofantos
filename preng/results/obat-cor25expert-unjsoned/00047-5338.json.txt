### Deriving a Second-Order Recurrence

We can derive a second-order recurrence by expressing the triangular number in terms of the sequence itself. Recall that:

$$
\text{Triangular}(n) = T(n) - T(n-1)
$$

Also, the triangular number satisfies:

$$
\text{Triangular}(n) = \text{Triangular}(n-1) + n
$$

Substituting into the first recurrence:

$$
T(n) = T(n-1) + \text{Triangular}(n)
$$
$$
= T(n-1) + \text{Triangular}(n-1) + n
$$
$$
= T(n-1) + (T(n-1) - T(n-2)) + n
$$
$$
= 2T(n-1) - T(n-2) + n
$$

### Final Recursive Formula

Thus, the recursive definition of the sequence is:

$$
a(n) = 
\begin{cases} 
0 & \text{if } n = 0 \\
1 & \text{if } n = 1 \\
2a(n-1) - a(n-2) + n & \text{if } n \geq 2
\end{cases}
$$

This recurrence uses only previous terms of the sequence and a linear term in $ n $, which is acceptable based on the examples provided in the problem.

def calculate_sequence(n):

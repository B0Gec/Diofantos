primorial(n) = primorial(n-1) * p_n

### ✅ **Implementation**

Here is a complete recursive implementation using a helper function to generate the `n`-th prime number:

```python
def is_prime(num):
    if num < 2:
        return False
    for i in range(2, int(num**0.5) + 1):
        if num % i == 0:
            return False
    return True

def nth_prime(n):
    count = 0
    candidate = 2
    while True:
        if is_prime(candidate):
            count += 1
            if count == n:
                return candidate
        candidate += 1

def primorial(n):
    if n == 0:
        return 1
    else:
        return primorial(n - 1) * nth_prime(n)
```

To compute the $ n $-th term of the sequence defined by the recurrence relation:

$$
a(n) = 
\begin{cases} 
1 & \text{if } n = 0, 1, 2 \\
\frac{1}{2} \sum_{k=0}^{n-1} \binom{n-1}{k} \cdot a(k) \cdot a(n-1-k) & \text{if } n \geq 3
\end{cases}
$$

we can implement a recursive function in Python. This recurrence is characteristic of the **Euler numbers** (A000111 in the OEIS), which count the number of alternating permutations of $ n $ elements.

---

### ✅ Python Implementation

```python
from math import comb

def a(n):
    if n in (0, 1, 2):
        return 1
    total = 0
    for k in range(n):
        total += comb(n - 1, k) * a(k) * a(n - 1 - k)
    return total // 2
```

---

### 🔍 Explanation

- **Base Cases**: For $ n = 0, 1, 2 $, the value is simply 1.
- **Recursive Case**: For $ n \geq 3 $, the function computes the sum over all $ k $ from 0 to $ n-1 $, using the binomial coefficient $ \binom{n-1}{k} $ and recursively calling `a(k)` and `a(n-1-k)`.
- **Division by 2**: The sum is divided by 2 to match the recurrence relation for the Euler numbers.

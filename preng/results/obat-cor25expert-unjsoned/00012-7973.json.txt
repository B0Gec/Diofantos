To compute the number of integer partitions of a non-negative integer `n` (i.e., the number of ways to write `n` as a sum of positive integers where the order does not matter), we can use the **pentagonal number recurrence** derived from Euler's Pentagonal Number Theorem.

This recurrence is based on the generalized pentagonal numbers, defined as:

$$
g_k = \frac{k(3k - 1)}{2}
$$

for integers $ k = 1, -1, 2, -2, 3, -3, \dots $, and the recurrence is:

$$
p(n) = \sum_{k} (-1)^{k-1} \cdot p(n - g_k)
$$

where the sum is over all $ k $ such that $ g_k \leq n $.

---

### ✅ Python Implementation

Here is a recursive implementation using memoization to avoid redundant computations:

```python
def partition(n, memo=None):
    if memo is None:
        memo = {}
    
    if n < 0:
        return 0
    if n == 0:
        return 1
    if n in memo:
        return memo[n]
    
    total = 0
    k = 1
    while True:
        # Generate generalized pentagonal numbers for k and -k
        g1 = k * (3 * k - 1) // 2
        if g1 > n:
            break
        sign = (-1) ** (k - 1)
        total += sign * partition(n - g1, memo)
        
        g2 = (-k) * (3 * (-k) - 1) // 2
        if g2 > n:
            break
        sign = (-1) ** (-k - 1)
        total += sign * partition(n - g2, memo)
        
        k += 1
    
    memo[n] = total
    return total
```

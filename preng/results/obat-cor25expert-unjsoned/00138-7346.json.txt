To generate the **n-th number in the sequence formed by reading Pascal's Triangle row-wise**, we can define a recursive function that leverages the structure of the triangle and the properties of triangular numbers.

### 🔢 **Understanding the Sequence**

Pascal's Triangle is structured such that:

- Row 0: [1]
- Row 1: [1, 1]
- Row 2: [1, 2, 1]
- Row 3: [1, 3, 3, 1]
- Row 4: [1, 4, 6, 4, 1]
- ...

If we read the triangle row by row, we get the sequence:

```
1, 1, 1, 1, 2, 1, 1, 3, 3, 1, 1, 4, 6, 4, 1, ...
```

This is the sequence we want to generate, where the **n-th element** corresponds to the **n-th number** in this flattened list.

---

### 🧠 **Approach Overview**

To find the **n-th element** in this sequence:

1. **Determine the row `m`** in which the n-th element lies.
2. **Determine the position `pos`** within that row.
3. If the position is at the edge of the row (i.e., `pos == 0` or `pos == m`), return `1`.
4. Otherwise, recursively compute the value as the sum of the two elements directly above it in the triangle.

---

### 🧮 **Mathematical Insight**

- The **triangular number** `T(m) = m * (m + 1) / 2` gives the total number of elements in the triangle up to and including row `m`.
- We find the **largest `m`** such that `T(m) ≤ n`.
- The **position within the row** is `pos = n - T(m)`.
- The **previous elements** in the triangle that contribute to the current value are located at:
  - `index1 = T(m - 1) + (pos - 1)`
  - `index2 = T(m - 1) + pos`

### ✅ **Recursive Function Implementation**

```python
def calculate_sequence(n):
    if n == 0:
        return 1

    # Find the row m such that T(m) <= n < T(m+1)
    m = 0
    while ( (m + 1) * (m + 2) ) // 2 <= n:
        m += 1

    # Compute the position within the row
    pos = n - (m * (m + 1)) // 2

    # If at the edge of the row, return 1
    if pos == 0 or pos == m:
        return 1

    # Compute the indices of the two elements above
    t_m_minus_1 = ( (m - 1) * m ) // 2
    index1 = t_m_minus_1 + (pos - 1)
    index2 = t_m_minus_1 + pos

    return calculate_sequence(index1) + calculate_sequence(index2)
```
